# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repo is

Hangyu Zhou's personal academic site, served by GitHub Pages as the user site https://zhou-hangyu.github.io/ from the root of `main`. There is no build step, package manager, linter or test suite: pages are hand-written static HTML, and `.nojekyll` makes Pages serve every file as-is. Pushing to `main` deploys.

Everything committed here is publicly served, including Markdown files like this one. Keep private notes and planning documents (for example `intake/`) out of git.

Preview locally with a server, because links such as `desire-model/` rely on directory-index resolution, which `file://` does not do:

```sh
python3 -m http.server 8000   # then open http://localhost:8000
```

## Structure

Each page is one self-contained HTML file with its own inline `<style>` and `<script>`. There is no shared stylesheet or template, so a site-wide change (colors, tracking, fonts) has to be made in every page.

- `index.html`: the homepage, in the original two-column layout. A warm sidebar (`#f5f2ed`) holds the photo, name, email and Font Awesome icon links; the right column has About Me, Publications/Preprints and Writings. Uses Verdana, with amber `#e8922a` links. Older sections (Research Interests, Experience, Teaching) are kept as commented-out HTML on purpose.
- `desire-model/index.html`: a standalone essay with its own design. It has a dark/light toggle stored in `localStorage`, KaTeX auto-render (`$…$` inline, `$$…$$` display, so a literal `$` in prose becomes math) and a GSAP ScrollTrigger diagram.
- `visitors.html`: unlisted stats page. See *Visitor tracking*.
- `neurep/`: generated by an external builder (commits titled `site: publish neurep …`). Do not edit by hand, because the next publish overwrites it. Its pages are `noindex`.
- `assets/`: `cv.pdf` (linked from the sidebar; update the CV by replacing this file), `hangyu-portrait.jpg` (600px web copy of `hangyu5.jpg`, used on the homepage), `favicon.svg`. The other `hangyu*` images are older photos.

Other repos share this domain through their own project Pages. `/lewi/` is `Zhou-Hangyu/lewi` (the LeWi paper's project page, demo and CSFRBench) and `/personal_website/` is `Zhou-Hangyu/personal_website`. Never create directories here with those names.

## Content conventions

- Publications: title linked to the arXiv page, then authors with the owner's name in `<b>`, then the venue in `<i>`, then optional bracketed links (`[Project page]`, `[Code]`). The peer-reviewed paper goes under Publications; arXiv papers go under Preprints, newest first.
- Keep the homepage minimal: no per-paper summaries and no news section. Details live in the CV and project pages.
- Each essay gets its own directory with an `index.html`, listed under Writings with a one-line TL;DR.

## Visitor tracking

Every public page, including the LeWi pages in the other repo, carries two trackers:

1. GoatCounter in `<head>`, site code `zhou-hangyu`: `<script data-goatcounter="https://zhou-hangyu.goatcounter.com/count" async src="https://gc.zgo.at/count.js"></script>`. Give the page a `<link rel="canonical">` so its view count is recorded under one stable path.
2. The MapMyVisitors pixel just before `</body>`: `<img src="https://mapmyvisitors.com/map.png?d=NCtmPpXBb5jvZC6scJCH9XjYBcQ2pgp4uDpI4EXO_sA&amp;cl=ffffff" style="display:none" alt="">`.

Google Analytics (`G-YMX6CSNKVN`) is on `index.html` only.

`visitors.html` fetches per-page counts from GoatCounter's public counter API (`/counter/<path>.json`) for the hard-coded `PAGES` list in its script. When you add a page, add it to that list too. Its "Views over time" chart has no time-series API to use: it asks for counts up to each period's start (`?end=YYYY-MM-DD`, a UTC midnight) and subtracts them, from `SINCE` (the first day with views) onward. The API only answers while "Allow adding visitor counts on your website" is on in GoatCounter's settings (otherwise it returns 403), and content blockers that use EasyPrivacy (uBlock Origin, Brave, AdGuard) block goatcounter.com, so their users see no counts. The map widget renders at 3200px for sharpness; the page's script scales it to the container and sizes the dots (`.jvectormap-marker`) so they stay the same size at any width. GoatCounter ignores `localhost` and `file://` views, so local previews don't inflate counts.
